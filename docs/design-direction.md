Design Direction Prompt

These reference images represent the visual direction and design language I want to draw inspiration from. Please thoroughly study the UI references before designing and use them as a strong source of inspiration for the overall aesthetic, composition, colour usage, typography, illustrations, spacing, and component design.

I want the final interface to feel playful, modern, expressive, polished, and visually memorable rather than generic or overly corporate.

The primary visual foundation should be built around a combination of:

Warm off-white / cream backgrounds
Deep navy or rich blue as a strong anchor colour
Bright, playful accent colours where appropriate, such as yellow, orange, green, purple, pink, or soft blue
High contrast between text and backgrounds
Rounded cards and large, soft corner radiuses
Bold, expressive typography
Playful illustrations and visual elements
Organic shapes and slightly imperfect, human-feeling design details

The first reference images demonstrate a strong balance between clean, structured UI and playful visual storytelling. I particularly like the use of cream/off-white surfaces paired with deep blue backgrounds, colourful illustrations, expressive typography, and visual elements that feel friendly and approachable.

The second reference demonstrates the use of colourful, illustrated content cards, large typography, visual storytelling, and a more human and emotionally engaging interface. I like how the illustrations are not just decorative but help make the product feel more memorable and approachable.

The third reference demonstrates a more bold, energetic, editorial style. I like the strong use of colour, oversized typography, playful illustrations, large rounded cards, and the way the interface feels almost like a carefully designed digital magazine or visual experience rather than a traditional software dashboard.

What I want you to take inspiration from

Please analyze the references and create an original design system inspired by the following principles:

1. Colour System

Use off-white and cream as the primary surface colours, with deep navy and blue as the primary anchor colours. Introduce additional accent colours only when they enhance the design and create visual hierarchy.

The colour palette should feel intentional and cohesive rather than random. Accent colours can be used for:

Important actions
Categories
Statuses
Illustrations
Highlights
Interactive elements
Visual storytelling

Do not make every section a different colour. Maintain a consistent visual system.

2. Typography

Use bold, confident typography for major headings. I want typography to feel expressive and have personality.

Large headlines should be visually prominent and may use:

Large font sizes
Strong weight contrast
Tight line heights
Editorial-style compositions
Occasional playful line breaks

Supporting text should remain clean and highly readable.

3. Layout and Components

Take inspiration from the large rounded mobile interfaces in the references.

Use:

Large rounded cards
Soft corners
Generous whitespace
Layered sections
Floating elements
Strong visual hierarchy
Clean navigation
Bold CTA buttons
Cards that feel tactile and approachable

Avoid making the interface feel like a standard SaaS dashboard filled with grids, tables, and generic components unless the product genuinely requires them.

4. Illustrations and Visual Storytelling

The illustrations are an important part of the visual identity.

Where appropriate, use illustrations, expressive graphics, abstract shapes, characters, or visual metaphors to make the experience feel more human and memorable.

Visual elements should feel:

Friendly
Playful
Modern
Slightly whimsical
Cohesive with the overall colour palette

The illustrations should support the product experience rather than feel like random stock artwork.

5. Overall Feeling

The final design should feel like a combination of:

A polished modern product
A playful mobile application
An editorial design system
A visually rich digital experience

It should feel premium but approachable, structured but expressive, and modern without being sterile.

Please do not directly copy any of the reference images. Instead, carefully understand the design principles behind them and create an original interface that captures the same level of creativity, visual confidence, and polish.

Before implementing the interface, first establish a cohesive design system based on these references, including:

Primary and secondary colours
Accent colours
Typography hierarchy
Button styles
Card styles
Border radius
Spacing system
Illustration direction
Icon style
Overall visual language

Then apply that design system consistently throughout the entire product.

The most important thing is that the final product should not look like a generic AI-generated SaaS interface. It should have a distinct visual identity, strong personality, and feel intentionally designed from the ground up using these references as inspiration.
